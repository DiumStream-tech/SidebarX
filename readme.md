# SidebarX

This plugin changes how the Discord sidebar looks. It turns your server list into a clean grid, styles the folders, and adds animated rings around servers when you get a notification.

## ⚠️ Status & Warnings

* **Still in Development:** This plugin is a work in progress. Things might break, change, or look weird sometimes.
* **Possible Bugs:** You might find some bugs here and there. If you do, feel free to report them, but keep in mind it's still being worked on.
* **Theme Conflicts:** Because this plugin heavily changes the server list and sidebar, it might not work well with other Discord themes. If you use another theme that also changes the server list, you might get visual glitches.

## Installation

You don't need to download anything else from this GitHub. There is only one file you need:

1. Download the **`SidebarX.plugin.js`** file.
2. Put it inside your BetterDiscord plugins folder. (Usually you can just open BetterDiscord settings, go to Plugins, and click "Open Plugin Folder").
3. Go back to Discord settings and enable SidebarX in the Plugins list.

## Features
    
* Grid layout for your servers.
* Custom folder styles.
* Animated rings for unread messages and pings (you can change the color and size in the plugin settings).
* A quick settings button right next to the Home button.
